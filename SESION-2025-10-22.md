## Problemas Resueltos

### 1. Eventos de Hover/Click No Funcionaban
**Problema:** Los nombres de filósofos no respondían a hover ni click

**Solución:**
- Agregado rectángulo invisible (`rect`) como área de hit detection
- Removidos `pointer-events` de elementos visuales individuales
- Delegados todos los eventos al grupo contenedor

```typescript
philoItems.append('rect')
  .attr('x', -50)
  .attr('y', -25)
  .attr('width', 400)
  .attr('height', 35)
  .attr('fill', 'transparent');
```

### 2. Tooltips Innecesarios en Statements
**Problema:** Los tooltips aparecían sobre los statements y no eran deseados

**Solución:**
- Removidas llamadas a `setTooltip()` de eventos de hover en statements

### 3. Separación de Comportamientos Hover vs Click
**Problema:** El hover movía elementos cuando solo debía desvanecer

**Solución:**
- Hover: Solo opacity (fade a 0.15-0.2), sin movimiento
- Click filósofo: Solo oculta otros (opacity 0), sin reorganización
- Click statement: Reorganiza en escalera compacta con redibujado de conexiones

### 4. Statements No Se Movían con Filósofos
**Problema:** Durante reorganización, solo los nombres se movían

**Solución:**
- Reemplazado `philosophers.find()` con lookup en datos SVG usando `.each()`
- Cálculo correcto de offsets desde posiciones originales de filósofos

```typescript
let origPhiloX = 0, origPhiloY = 0;
svg.selectAll('.philosopher-label').each(function(p: any) {
  if (p.id === d.philosopherId) {
    origPhiloX = p.x || 0;
    origPhiloY = p.y || 0;
  }
});
```

### 5. Reset No Restauraba Conexiones Originales
**Problema:** Click afuera no eliminaba conexiones redibujadas

**Solución:**
- Agregado check de conteo de conexiones
- Remoción completa y redibujado de conexiones originales si hay discrepancia

```typescript
const currentConnectionCount = svg.selectAll('.connection').size();
if (currentConnectionCount === 0 || currentConnectionCount < connections.length) {
  svg.selectAll('.connection').remove();
  // Redibujar conexiones originales
}
```

### 6. Errores de Runtime en Opacity de Conexiones
**Problema:** `Cannot read properties of undefined (reading 'statementFromId')`

**Solución:**
- Agregados null guards en callbacks de opacity

```typescript
.style('opacity', function(d: any) {
  if (!d || !d.statementFromId || !d.statementToId) {
    return 1;
  }
  // resto de la lógica
});
```

### 7. Solapamiento de Nombres y Fechas
**Problema:** Textos se encimaban porque se usaba cálculo aproximado de ancho

**Solución:**
- Uso de `getBBox().width` para medición exacta del texto renderizado
- Posicionamiento dinámico basado en ancho real

```typescript
philoItems.each(function(d: any) {
  const nameWidth = nameText?.getBBox().width || (d.name.length * 10);
  group.append('text').attr('x', nameWidth + 10)
});
```

### 8. Espaciado Vertical Fijo e Inadecuado
**Problema:** Filósofos con 2 statements tenían mucho espacio, con 4 quedaba poco

**Solución:** Espaciado dinámico basado en número de statements

**Antes:**
```typescript
const diagonalStepY = 150; // Valor fijo
const philosopherY = startY + (i * diagonalStepY);
```

**Después:**
```typescript
const basePhilosopherHeight = 70;
const statementSpacing = 18;

let cumulativeY = startY;
philosophers.forEach((p, i) => {
  const numStatements = (p.statements || []).length;
  const philosopherTotalHeight = basePhilosopherHeight + (numStatements * statementSpacing);
  
  p.y = cumulativeY;
  cumulativeY += philosopherTotalHeight;
});
```

**Resultado:**
- Filósofo con 2 statements: 70 + (2 × 18) = 106px
- Filósofo con 4 statements: 70 + (4 × 18) = 142px
- Filósofo con 6 statements: 70 + (6 × 18) = 178px

### 9. Espaciado Muy Amplio (Refinamiento)
**Problema:** Demasiado espacio entre elements, layout poco compacto

**Solución:**
- `statementSpacing`: 26px → 18px (reducción 31%)
- Offset primer statement: 40px → 30px (reducción 25%)

### 10. Cursor Interfiriendo con Animaciones
**Problema:** El hover durante animaciones las interrumpía

**Solución Implementada (con issues):**
- Agregado estado `isAnimating`
- Bloqueo de eventos hover cuando `isAnimating === true`
- Timeout de 600ms para desbloquear

```typescript
const [isAnimating, setIsAnimating] = useState(false);

.on('mouseenter', (event, d: any) => {
  if (!isAnimating) setHoveredPhilosopher(d.id);
})

.on('click', (event, d: any) => {
  setIsAnimating(true);
  // ... lógica de click
  setTimeout(() => setIsAnimating(false), 600);
});
```

**Estado:** Implementado pero causaba problemas, quedó pendiente para mañana.

  - `filteredStatement`: number | null
  - `isAnimating`: boolean

### Flujo de Interacciones

**Hover sobre filósofo:**
1. `setHoveredPhilosopher(id)`
2. Segundo useEffect detecta cambio
3. Fade a 0.15 elementos no relacionados
4. Conexiones a 0.2 si no relacionadas

**Click sobre filósofo:**
1. `setFilteredPhilosopher(id)`, clear `filteredStatement`
2. Segundo useEffect entra en modo filter
3. Opacity 0 a todos los demás filósofos
4. Sin movimiento de posiciones
5. Oculta todas las conexiones

**Click sobre statement:**
1. `setFilteredStatement(id)`, clear `filteredPhilosopher`
2. Segundo useEffect detecta y reorganiza
3. Calcula elementos activos (statement + conexiones + filósofos relacionados)
4. Reorganiza en escalera compacta empezando en (80, 40)
5. Mueve filósofos Y sus statements juntos
6. Redibuja conexiones con nuevas posiciones después de 550ms
7. Fade a 0.15 elementos no relacionados

**Click en fondo (reset):**
1. Clear ambos estados: `setFilteredPhilosopher(null)`, `setFilteredStatement(null)`
2. Transición de vuelta a posiciones originales
3. Si conexiones fueron redibujadas, las elimina y restaura originales
4. Opacity de todos a 1

## Notas Técnicas Importantes

### D3 + React
- Dos useEffects: uno para dibujo inicial, otro para interacciones
- D3 maneja el DOM directamente (no usar React virtual DOM para SVG)
- Estados React controlan qué se renderiza, D3 aplica los cambios

### Gestión de Conexiones
- Conexiones originales nunca se modifican en data
- Al reorganizar, se guardan en variable temporal y se redibujan
- Reset requiere eliminar y recrear desde data original
- Null guards necesarios porque conexiones redibujadas pierden data binding

### Cálculo de Posiciones
- `getBBox()` solo funciona después de que el elemento está en el DOM
- Usar `.each()` para acceder a `this` del elemento D3
- Transform translate para todos los movimientos (no cambiar x/y directamente)
- Offsets calculados desde posiciones de filósofos, no absolutas

### Performance
- Evitar re-renders innecesarios de todo el SVG
- Transiciones de 550ms balancean fluidez y responsiveness
- `pointer-events` management evita captura de eventos en elementos incorrectos

## Lecciones Aprendidas

1. **Event Delegation:** Rectángulos invisibles son más confiables que eventos en elementos visuales pequeños
2. **Data Binding:** D3 data binding se pierde al remover/recrear elementos - guardar copia cuando sea necesario
3. **Medición de Texto:** `getBBox()` es la única forma precisa, cálculos aproximados fallan
4. **Estado vs Animación:** Cambios de estado durante animaciones pueden causar conflictos - considerar refs
5. **Git Workflow:** Commits frecuentes con mensajes descriptivos facilitan debugging futuro
